# Elysia - A World Beyond Time

A cinematic, single-page experience inspired by quiet water, ancient stone, and the passing of light.

## Project status

Repository initialized. Website implementation and deployment will follow the approved media handoff and visual and technical verification.

The agreed media composition uses two original Gemini-generated videos (Hero and Nature) and three static scenes (Featured, Philosophy, and Temple). Static scenes will remain still.

## Planned stack

React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide React. Instrument Serif regular and italic for display typography.

## Media and provenance

Only approved, publication-ready website assets belong in `public/media/`. Asset provenance and processing details will accompany the final media. Private source instructions, account information, temporary transfer URLs, and credentials are excluded.

## Release checks

Responsive layouts, keyboard navigation, reduced motion, loading and error fallbacks, playback controls, and video loop boundaries will be verified before deployment.
